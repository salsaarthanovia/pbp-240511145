# Analisis Komparatif Platform: Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript/TypeScript; backend dapat memakai bahasa lain. | C/C++, C#, Java, Python, Swift, dan bahasa lain sesuai framework/OS. | Kotlin/Java untuk Android; Swift untuk iOS; JavaScript/Dart/Kotlin Multiplatform pada pendekatan lintas platform. |
| Arsitektur | Umumnya client–server; antarmuka berjalan di browser dan berkomunikasi dengan server/API. | Aplikasi berjalan di sistem operasi komputer; dapat memakai arsitektur lokal atau client–server. | Aplikasi berjalan di perangkat dengan akses ke API OS, sensor, dan layanan jaringan. |
| Cara distribusi | Dipublikasikan di server/hosting dan diakses melalui URL/browser. | Installer atau paket aplikasi, toko aplikasi desktop, atau distribusi internal. | Google Play, Apple App Store, atau distribusi/pemasangan lain yang didukung OS. |
| Keunggulan | Mudah diakses lintas perangkat, pembaruan terpusat, tidak selalu perlu instalasi. | Integrasi OS dan perangkat keras yang kuat; cocok untuk pekerjaan kompleks/offline. | Portabel; dapat memanfaatkan kamera, GPS, notifikasi, dan sensor perangkat. |
| Keterbatasan | Bergantung pada browser dan jaringan untuk banyak fitur; akses perangkat dibatasi kebijakan browser. | Perlu memperhatikan kompatibilitas OS/perangkat; instalasi dan pembaruan lebih terpisah. | Perlu mempertimbangkan ukuran layar, baterai, izin, fragmentasi perangkat, dan proses publikasi. |
| Contoh aplikasi | Google Docs versi web, Gmail web, Wikipedia. | Visual Studio Code, LibreOffice, Blender. | WhatsApp mobile, Google Maps, aplikasi mobile banking. |
